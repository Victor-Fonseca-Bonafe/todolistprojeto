# TaskFlow - To Do List

Uma To-Do List moderna, clean e minimalista feita **apenas com HTML e CSS**, com persistência de dados.

![TaskFlow Preview](https://via.placeholder.com/800x400/16161e/6e56cf?text=TaskFlow+Preview)

## ✨ Funcionalidades

- ✅ Adicionar tarefas com descrição
- 🔴 Seleção de prioridade (Alta, Média ou Baixa)
- 🎨 Estilização condicional por prioridade com cores distintas
- ✓ Marcar tarefas como concluídas (com linha riscada)
- 🗑️ Excluir tarefas
- 💾 Persistência automática com **LocalStorage**
- 🌙 Design dark moderno e clean
- ⚡ Animações suaves e transições elegantes
- 📱 Totalmente responsivo

## 🛠️ Tecnologias Utilizadas

- **HTML5** Semântico
- **CSS3** (Flexbox, Animações, Variáveis, Pseudo-elementos)
- **JavaScript** (Vanilla JS - sem frameworks)
- **LocalStorage** para persistência de dados

## 🎨 Design & Experiência

- Interface minimalista com tema escuro
- Cores suaves e contrastantes
- Animações fluidas ao adicionar, completar e remover tarefas
- Feedback visual claro para cada ação
- Prioridades destacadas com tags coloridas
